## Шаги

- **3.1 Сверка.** Текущий голосовой слой (`VoiceSession`, TTS, VAD) против раздела «Что осталось» голосового плана; без
  причины ничего не переделывать.
- **3.2 Режим.** Явный переключатель (кнопка и настройка; хоткей — если свободен). Цикл: Listening → конец фразы по VAD →
  финальный Whisper → отправка через координатор, только Chat → ответ голосом → снова Listening. Пока LINK говорит,
  микрофон не слушает; push-to-talk перебивает сразу.
- **3.3 Задержка.** Порог конца фразы 0,6–0,7 с; сигнал «услышал» сразу после конца фразы; waiting cues — по правилам
  голосового плана.
- **3.4 Подсказка** `Interaction mode: Conversation` — в Chat, но не в Direct.
- **3.5 Ошибки распознавания.** Транскрипт виден в поле; исправление — перенаправлением из снимка, без повторной
  диктовки. В Agent голосом — никогда автоматически (только через карточку подтверждения этапа 4).
- **3.6 Замеры и документы.** Конец фразы → отправка, отправка → первая фраза ответа, CPU в режиме слушания — в отчёт.
  Голосовой план (сделанное), README, PROJECT_CONTEXT, статус этапа в плане §2.

## Готово, когда

- Выполняется «Критерий Jarvis-like v1» из голосового плана.
- В режиме слушания CPU не выше, чем при удержании push-to-talk; выключенный режим ничего не слушает.
- Сборка Release — 0 warnings, тесты зелёные.

## Чеклист пользователю

1. Включить режим, задать вопрос голосом без клавиш — ответ голосом, затем LINK снова слушает.
2. Перебить ответ push-to-talk — звук стихает сразу, новый вопрос уходит.
3. Длинный ответ: голосом — коротко, полностью — текстом на экране.
4. Выключить режим — микрофон больше не слушает (индикатор микрофона Windows гаснет).
5. Ошибка распознавания: исправить текст и перенаправить без повторной диктовки.
