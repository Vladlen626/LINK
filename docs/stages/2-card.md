# Этап 2 — карточка и панель: куда уйдёт и что будет

Команда для нового чата: «Выполни этап из docs/stages/2-card.md».

- **Зачем:** по карточке сразу видно, куда уйдёт сообщение, что уйдёт с ним и что сделает каждая кнопка; меньше
  скрытых режимов и стрелок; панель — две явные вкладки.
- **Уже есть:** строка Sees и чип приложения (этап 1); маршруты Chat / Direct / Agent (`MainWindow.Chat.cs`,
  `RouteOptions`), перенаправления ↻ Deeper / Direct / Fresh screen / Agent и ✎ Edit, подсказка `↳ Agent?`
  (`MainWindow.Agent.cs`, `ActionVerbs`), чип задачи и состояние проекта (`LinkProject.CurrentTask`, `ProjectState`),
  панель проекта или агента (`MainWindow.Panel.cs`, `ProjectPanel`, `AgentPanel`), HISTORY и AGENT SESSIONS.
- **Зависит от:** этап 1. Прочитать: `CLAUDE.md`, [план](../WORKSPACE_PLAN.md) §3, §4 целиком, §6.2, §8.

## Шаги

- **2.1 Адресат на кнопке.** Кнопка отправки называет, куда уйдёт: `→ ChatGPT` или `→ Claude task` / `→ Codex task`
  (агент проекта; открывает карточку задачи, ничего не запуская). Выбор `To: ChatGPT ▾` — два адресата: ChatGPT и
  агент проекта. Подсказки кнопок — глагол и цель.
- **2.2 Чипы вместо Direct.** Direct уходит из выбора; всё, что LINK добавляет (заметка проекта, приложение и окно,
  авто-кадр), — видимые элементы с × на один вопрос; `Only my text` (переключатель в строке чипов) отправляет без них —
  то же, что Direct (§6.2 плана). Сохранённый `Route: Direct` грузится как Chat с выключенным `Only my text`. Тесты
  `PromptRequest`: каждый чип убран, все убраны, `Only my text`.
- **2.3 Заметка проекта.** `CurrentTask` и `ProjectState` — одна заметка: в панели одно поле «Project note» (первая
  строка — фокус), в карточке чип проекта показывает первую строку (× — без заметки на один вопрос, клик — правка в
  панели). В Chat — один чип с текстом заметки вместо строки «Current task» и чипа «Project state»; агенту — так же.
  `Normalize()` переносит старую задачу первой строкой; тест на старый JSON.
- **2.4 Под ответом два действия.** `Ask again ▾` (Deeper · With a fresh screen · Only my text · Edit the question) и
  `→ Agent task` (как сейчас ↻ Agent — тот же снимок; этап 4 даст бриф из ответа). Подсказка `↳ Agent?` по глаголам
  уходит вместе с `ActionVerbs`; `Ctrl+Enter` остаётся.
- **2.5 Строка состояния с подлежащим.** Одна строка и подсказка tray говорят, кто что делает (§4.3 плана):
  `ChatGPT is answering · 12 s`, `Claude is working · <шаг> · 4:12`, `Claude needs you: …`, `Done`. Состояние — из
  `LinkState` и событий агента, без новых таймеров сверх одного секундного на время работы.
- **2.6 Пилюля агента в заголовке.** Пока у проекта есть открытая задача: `Claude · 4:12`, `Claude needs you`,
  `Claude done` — клик открывает панель на вкладке Task. Пусто — пилюли нет.
- **2.7 Вкладки панели.** Явные `Project | Task` вместо неявного переключения: Project — заметка, беседа, рабочая папка
  (карта, skills, проверка), History; Task — нынешние карточка и Activity агента (этап 3 их перестроит). Пустая Task:
  «No task. Ctrl+Enter in the question, or → Agent task under an answer».
- **2.8 Одна History.** HISTORY и AGENT SESSIONS — одна лента по времени: ответы ChatGPT и сессии агента с иконкой;
  клик — ответ в карточке или сессия во вкладке Task (этап 3 заменит сессии задачами).
- **2.9 Документы.** README (раздел 1 и 2, рисунки `overlay.svg`, `panel.svg`, `overview.svg` через `preview-svg`),
  PROJECT_CONTEXT (решения: адресаты, чипы, заметка, вкладки, одна история).

## Не делать

- Перестройку Activity и записи задач (этап 3), бриф из ответа (этап 4).
- Новые окна, анимации, рост высоты карточки; новые настройки, без которых можно обойтись.

## Готово, когда

- По карточке без подсказок видно: куда уйдёт сообщение, что уйдёт с ним (Sees и чипы), что делает каждая кнопка.
- В выборе маршрута нет Direct, `Only my text` делает то же; старые `settings.json` и `projects.json` грузятся.
- Под ответом два действия; заметка проекта одна; вкладки Project / Task; одна History; пилюля агента.
- Сборка 0/0, тесты зелёные.

## Чеклист пользователю

1. Обычный вопрос: кнопка говорит `→ ChatGPT`, Sees и чипы показывают, что уйдёт; × на чипе — на один вопрос.
2. `Only my text` — ответ без строк LINK (как прежний Direct).
3. `To: ▾` → агент: кнопка `→ Claude task` открывает карточку, ничего не запуская.
4. Заметка проекта: первая строка видна в карточке; старые задача и состояние на месте.
5. `Ask again ▾` → Deeper и With a fresh screen; `→ Agent task` открывает карточку с тем же снимком.
6. Во время ответа и работы агента строка состояния говорит, кто что делает; пилюля открывает Task.
7. Вкладки Project | Task; History показывает и ответы, и сессии агента.
