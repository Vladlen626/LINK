# Этап 1 — окно: Hide, Expand-панель, иконка tray, звуки

Команда для нового чата: «Выполни этап из docs/stages/1-window.md».

- **Зачем:** пункт брифа «компактный UI»: окно полностью прячется, подробности открываются рядом, а не внутри
  карточки. Панель этапа потом примет Agent/Activity (этап 4).
- **Уже есть:** новый дизайн карточки, скрытие хоткеем Ctrl+Alt+Space и Alt+F4 (`ToggleVisible`), капсула Collapse
  (`SetCollapsed` в `MainWindow.Sizing.cs`), balloon в tray, общий waveOut-плеер.
- **Зависит от:** ничего. Прочитать: `CLAUDE.md`, память проекта, [план](../AGENT_HARNESS_PLAN.md) §2 (как вести
  этап), §6.6, §7.1, §7.4–§7.5, §9.

## Перед началом

- `git status`, `git log --oneline -20`: шаги с коммитами `[1.x]` уже сделаны — продолжить с первого несделанного.
- Если в рабочем дереве незакоммиченная работа по голосу (TTS, `RequestLatency`) или чужие правки в файлах этапа —
  остановиться и попросить пользователя сначала её закоммитить.

## Шаги

- **1.1 Hide.** Кнопка в заголовке вместо Collapse, двойной клик по заголовку, Esc в простое (нет речи и запроса) —
  всё прячет overlay так же, как `ToggleVisible`. Капсулу и `SetCollapsed` убрать; `IsCollapsed` мигрировать в
  следующей `SchemaVersion` так, чтобы первый запуск был видимым.
- **1.2 Хост боковой панели.** Отдельное owned-окно в стиле карточки; кнопка Expand в заголовке; сторона — где больше
  места в рабочей области монитора карточки; следует за карточкой при перетаскивании и изменении размера; прячется
  вместе с Hide; одна панель за раз; ширина и открытость — в настройках (defaults + `Normalize()`). Несколько
  мониторов и DPI.
- **1.3 Панель Project/Context:**
  - текущая задача — переезжает из карточки; в карточке остаётся чип, если задача задана;
  - состояние проекта (план §6.6) — текст и дата актуальности в `LinkProject` (старый `projects.json` грузится); в
    запрос уходит видимым чипом, который можно убрать; отдельный `ContextItemType`, чтобы этап 2 не брал его в Direct;
  - беседа: строка связанной беседы, New chat, Open chat — переезжают из карточки; точка состояния ChatGPT остаётся в
    карточке (рядом с проектом или в строке статуса), чтобы «Sign in to ChatGPT» и ошибки были видны без панели;
  - история: 10 последних вопросов и ответов проекта — отдельный файл в папке данных проекта через `AtomicJsonFile`,
    не в `projects.json`;
  - рабочая папка проекта `WorkspaceRoot` — явный выбор папки (нужна агенту); по окну не угадывать.
- **1.4 Иконка tray по состоянию:** простой / работает / нужно решение / готово (до следующего открытия LINK); варианты
  рисует `LinkIconFactory`, подсказка tray — текущий статус.
- **1.5 Звуки** ≤ 150 мс: слушаю, отправлено, нужно решение, готово, ошибка — через общий waveOut-плеер; тоны в коде
  или маленькие ресурсы; пока LINK говорит, звуки молчат, кроме «нужно решение»; переключатель в Settings (включено).
- **1.6 Замеры и документы.** Простой CPU и память с открытой и закрытой панелью, время открытия overlay — в отчёт.
  README (Hide, Expand, звуки, совет: F13–F24 годятся для push-to-talk на макропаде или педали), PROJECT_CONTEXT,
  статус этапа в плане §2.

## Не делать

- Содержимое Agent/Activity (только место под него), изменения отправки запроса (это этап 2), новые зависимости.

## Готово, когда

- Hide тремя способами; хоткей показа возвращает; первый запуск после обновления видимый.
- Панель открывается на свободной стороне у любого края монитора, не сдвигая карточку, и следует за ней.
- Чип состояния проекта виден и убирается; история своя у каждого проекта; рабочая папка сохраняется.
- Простой CPU и память не выросли заметно; сборка Release — 0 warnings, тесты зелёные.

## Чеклист пользователю

1. Hide кнопкой, двойным кликом и Esc; Ctrl+Alt+Space возвращает; ответ, начатый до Hide, дописан.
2. Expand у левого и правого края монитора — панель на свободной стороне; перетаскивание — панель следует.
3. Текущая задача и состояние проекта правятся в панели; чип состояния виден в карточке и убирается.
4. История показывает последние ответы проекта; при смене проекта — его история; рабочая папка сохраняется.
5. Tray: во время запроса иконка «работает»; ответ пришёл, пока LINK скрыт, — «готово».
6. Звуки слышны, молчат во время речи и выключаются в Settings.
