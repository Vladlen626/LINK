# Этап 5 — модели, передача и экономия

Команда для нового чата: «Выполни этап из docs/stages/5-models-handoff.md».

- **Зачем:** работа идёт на модели, которой хватает, и переходит на другую — в той же сессии или к другому агенту —
  одной командой, почти с того же места; у лимита LINK предлагает выход заранее, а после сброса возвращает задачу.
- **Уже есть:** модель и effort в Settings и карточке (`AgentSettings`, `EffortFor`, `ModelFor`), передача v1
  (`AgentCoordinator.HandOffTask`: задача, последние слова, 40 шагов, файлы, заметка), запись задачи, план агента,
  окна лимитов и Continue at (этап 3), бриф и карточка с брифом (этап 4).
- **Зависит от:** этапы 3 и 4. Прочитать: `CLAUDE.md`, [план](../WORKSPACE_PLAN.md) §3, §4.4, §5, §6.5–§6.7, §8, §9.

## Перед началом

- `git status`, `git log --oneline -20`: шаги с коммитами `[5.x]` уже сделаны — продолжить с первого несделанного.
- Предложить пользователю значения уровней по умолчанию (§6.5 плана) из списков моделей обоих CLI и получить «да».
- Спросить про живые прогоны: смена модели при resume у обоих CLI и один настоящий handoff для замера (5.9).

## Шаги

- **5.1 Уровни.** `AgentLevel { Light, Standard, Deep }` → (модель, effort) у каждого агента: Settings → Agents —
  три строки на агента; карточка и Task — `Deep · Opus 5.5 · high`. Старые выбранные модель и effort становятся
  уровнем Standard; `Normalize()`; тесты.
- **5.2 Модель в той же сессии.** Hand off ▾ в Task: «Claude · Sonnet (same session)» и т. п. — продолжение текущей
  сессии с другой моделью (Claude `--resume … --model`, Codex `exec resume` с моделью — по `--help`), строка
  `ModelSwitch` в ленте, подсказка про один промах кэша. Проверить живым прогоном или фикстурой.
- **5.3 План сильной, работа обычной.** Plan first идёт на Deep, Run the plan продолжает ту же сессию на Standard —
  у обоих агентов; настройка, по умолчанию включена.
- **5.4 Escalate.** После двух красных возвратов проверки или метки петли — `Escalate` (та же сессия на Deep) рядом со
  Start over. Сам LINK уровень задачи не понижает.
- **5.5 Свои ответы LINK — на Light.** Карта, Save as skill и заметка Start over — на уровне Light по умолчанию
  (настройка в Settings → Agents).
- **5.6 Бриф передачи v2.** `HandOffTask` строит бриф из записи задачи (§6.7 плана): цель и бриф, все поправки,
  последний план (сделано, осталось), файлы с `+/-`, последняя проверка с концом вывода, последние слова агента,
  указатели на карту, skills и `.mcp.json`, правило «сначала посмотри изменения». Бюджет ~1,5k токенов: сокращаются
  шаги, а не цель и поправки. Тесты на состав и обрезку.
- **5.7 Превью передачи.** Hand off ▾ → «Codex (new session)» открывает карточку с брифом v2 (правится), уровнем
  получателя и кнопкой Hand off; строка `HandOff` в ленте; What Link gave показывает бриф.
- **5.8 Лимит заранее.** Окно агента ≥ 90 % или `rate_limit_event` с предупреждением во время задачи — тихая строка в
  Task и пилюле: `Claude is near its limit (92%, resets 15:45)` — Hand off to Codex · Switch to Sonnet · Go on. Сам
  ничего не делает.
- **5.9 Return to Claude.** После передачи, когда окно первого агента сброшено: `Return to Claude` — `--resume` его
  сессии со сводкой того, что сделал второй (файлы, проверка, его последние слова), а не новая сессия.
- **5.10 Замер.** С разрешения пользователя — одна настоящая передача на небольшой задаче: токены первых запросов
  получателя и время до первой правки против нового старта с той же целью; строки `[Agent]`. Итог — в
  PROJECT_CONTEXT, «Состояние и дальше».
- **5.11 Документы и тесты.** README (уровни, Hand off ▾, Escalate, Return, лимиты), PROJECT_CONTEXT (решения и
  замер).

## Не делать

- Передачу или смену модели без клика пользователя; «дешёвый старт» без его выбора.
- Бриф, который пишет сам агент или ChatGPT (возможно позже); поправки без остановки (этап 6).

## Готово, когда

- Уровни видны с моделью и effort; смена модели продолжает ту же сессию; Plan first → Run the plan меняет уровень.
- Escalate предложен после провала; свои ответы LINK — на Light.
- Hand off к другому агенту показывает бриф v2 до отправки, бриф в бюджете; лимит заранее предложен;
  Return to Claude продолжает его сессию.
- Замер записан; сборка 0/0, тесты зелёные.

## Чеклист пользователю

1. Settings → Agents: уровни Light / Standard / Deep у Claude и Codex — согласиться или поправить.
2. Задача на Standard → Hand off ▾ → Sonnet или Opus в той же сессии: агент помнит сделанное.
3. Plan first: план на Deep, Run the plan — на Standard.
4. Красная проверка дважды → Escalate.
5. Hand off → Codex: превью брифа, правка, передача; Codex не переделывает сделанное.
6. Позже, после сброса лимита — Return to Claude.
